{{ "Predicted coverage" | tr }}

{{ "Meshview can display a predicted coverage boundary for a node. This is a model estimate, not a guarantee of real-world performance." | tr }}

{{ "How it works" | tr }}

{{ "The coverage boundary is computed with the Longley-Rice / ITM propagation model in area mode, from NTIA's reference implementation, built into the server. Area mode estimates average path loss over generic terrain and does not use a terrain profile. This means it captures general distance effects, but does not account for terrain shadows, buildings or foliage." | tr }}

{{ "What you are seeing" | tr }}

{{ "The map draws a perimeter (not a heatmap) that represents the furthest distance where the predicted signal strength is above a threshold, -120 dBm by default. The model is run in many directions around the node, and the last point above the threshold in each one forms the outline." | tr }}

{{ "Key parameters" | tr }}

  • {{ "Frequency" | tr }}: {{ "default" | tr }} 907 MHz
  • {{ "Transmit power" | tr }}: {{ "default" | tr }} 20 dBm
  • {{ "Antenna heights" | tr }}: {{ "default" | tr }} 5 m (TX) {{ "and" | tr }} 1.5 m (RX)
  • {{ "Reliability" | tr }}: {{ "default" | tr }} 0.5 ({{ "median" | tr }})
  • {{ "Terrain irregularity" | tr }}: {{ "default" | tr }} 90 m ({{ "average terrain" | tr }})

{{ "Limitations" | tr }}

  • {{ "No terrain or building data is used (area mode only)." | tr }}
  • {{ "Results are sensitive to power, height and threshold." | tr }}
  • {{ "Environmental factors can cause large real-world deviations." | tr }}
